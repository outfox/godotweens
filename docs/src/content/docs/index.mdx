## Structured, readable, reusable

A tween in tweens.gd is a definition: one object that names the property,
endpoints, timing, and easing together. It reads top to bottom, you can name it
and start it from any number of places, and you change it in one spot when the
motion should feel different. Refactoring and reauthoring motion become ordinary
code edits instead of a hunt through scattered call chains.

## Choose your language

<Tabs>
  <TabItem label="C#">

The C# implementation is available in this repository. Start with a project
reference or a locally built `tweens.gd` package while its first public release
is pending.

```csharp
using Godot;
using tweens.gd;

var arrive = new Tweens.Position2D
{
    To = new Vector2(400, 180),
    Duration = 0.6,
    Ease = EaseType.CubicOut,
};

var movement = sprite.Tween(arrive);
if (await movement.End == Reason.Completed)
    GD.Print("Arrived");
```

[Install the C# library](/csharp/installation/).
